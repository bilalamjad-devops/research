### **Real-Life Example (Chai Ki Rehari / Order Dene Ka Tareeqah)**

Sochein aap ek dukan par jayein aur **2 cheezon ka order** dein: *Chai aur Samosa*.

Order dene ke **2 aam tareeqay (Conventions)** ho sakte hain:

1. **Tareeqah A (C Convention):**
Aap pehle *Samosa* bolte hain, phir *Chai* (Ulta order: **Right to Left**). Phir jab order poora ho jata hai, toh **aap khud (Caller)** counter se kachra saaf karte hain.
2. **Tareeqah B (Pascal Convention):**
Aap pehle *Chai* bolte hain, phir *Samosa* (Seedha order: **Left to Right**). Jab order poora hota hai, toh **dukan wala (Callee)** counter saaf karta hai.

### **Computer Mein Kya Hota Hai?**

Jab ek function (code) doosre function ko koi data bhejta hai, toh computer mein **data bhejne ke 2 aam tareeqay (Prevalent Calling Conventions)** hote hain:

1. **C Calling Convention** (C / C++ language mein use hota hai)
2. **Pascal Calling Convention** (Pascal language mein use hota hai)
