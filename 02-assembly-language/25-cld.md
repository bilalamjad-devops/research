Sahi Option Hai: **Cld**

---

### **1-Line Memory Trick:**

* **`CLD`** = **CL**ear **D**irection Flag (DF ko `0` karta hai $\rightarrow$ **Forward** / Aage barhna).
* **`STD`** = **ST**art / **ST**et **D**irection Flag (DF ko `1` karta hai $\rightarrow$ **Backward** / Peeche barhna).

---

> **Exam Shortcut:**
> String operations mein **Clear** ke liye hamesha **`CLD`** istemal hota hai!
