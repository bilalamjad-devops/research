### **MCQ 62:**

Interrupt that is used in debugging with help of trap flag is

**Sahi Option:** **INT 1**

* **1-Line Trick:** **Trap Flag / Single-Stepping (Debugging)** = **INT 1**
*(Note: INT 3 breakpoint ke liye use hota hai, lekin Trap Flag ke sath hamesha INT 1 kaam karta hai).*

---

### **MCQ 63:**

INT for arithmetic overflow is

**Sahi Option:** **INT 4**

* **1-Line Trick:** **Overflow (INTO instruction)** = **INT 4**

---
