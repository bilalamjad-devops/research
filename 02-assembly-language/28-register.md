### **1-Line Memory Trick:**

* **`CX`** = **C**ount Register (Looping, string repetitions aur shift/rotate counter ke liye istemal hota hai).

---

### **Fast Recall Table (General Purpose Registers):**

| Register | Full Name | Primary Role |
| --- | --- | --- |
| **`AX`** | **A**ccumulator Register | Arithmetic/Logic & I/O operations |
| **`BX`** | **B**ase Register | Base address calculation for memory |
| **`CX`** | **C**ount Register | **Loop & String repetition counter** |
| **`DX`** | **D**ata Register | Multiplication/Division & I/O Port address |


### **Crisp Summary: Registers**

* **What it is:** CPU ke andar ka **sab se fast memory component** jo direct processing ke liye data hold karta hai.
* **Why "Memory":** Ye temporary storage cells hain jo RAM ki tarah data `READ` aur `WRITE` kar sakte hain—lekin RAM se lakho guna fast.
* **Why "Results":** CPU calculations ke darmiyani (intermediate) results direct registers mein rakhta hai (e.g., `AX`, `BX`).
* **Why "Scratch Pad RAM":** Ye CPU ki **rough copy/scratch pad** hai—jis par wo quick calculations likhta aur mita ta rehta hai.

---

> **1-Line Bottom Line:** Register CPU ka apna super-fast temporary memory box hai jahan wo kaam karte waqt rough calculation karta hai.
