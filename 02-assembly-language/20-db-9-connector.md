### **DB-9 Serial Port Complete Pinout Table (CS401 Exam Summary):**

DB-9 connector (RS-232 Serial Port) par Total **9 Pins** hoti hain. Exam mein aksar inme se kisi ek ka pin number pucha jata hai:

| Pin Number | Signal Name | Full Form / Purpose |
| --- | --- | --- |
| **Pin 1** | **CD** | **Carrier Detect** |
| **Pin 2** | **RXD** | **Receive Data** |
| **Pin 3** | **TXD** | **Transmit Data** |
| **Pin 4** | **DTR** | **Data Terminal Ready** |
| **Pin 5** | **GND** | **Signal Ground** (Middle Pin) |
| **Pin 6** | **DSR** | **Data Set Ready** |
| **Pin 7** | **RTS** | **Request To Send** |
| **Pin 8** | **CTS** | **Clear To Send** |
| **Pin 9** | **RI** | **Ring Indicator** |

---

> **Exam Shortcut Tip:**
> * Sab se **pehli pin (Pin 1)** $\rightarrow$ **CD** (Carrier Detect)
> * Bilkul **center wali pin (Pin 5)** $\rightarrow$ **GND** (Ground)
> * Sab se **aakhri pin (Pin 9)** $\rightarrow$ **RI** (Ring Indicator)
