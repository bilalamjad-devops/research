

## 🟢 C. SIEM

Full Form:

Security Information and Event Management

---

Think about AWS.

Suppose you have

* EC2
* RDS
* S3
* Firewall
* Antivirus

Every service generates logs.

Example:

```
Login Failed

User Deleted

Port Scan

Malware Found

Root Login

SSH Attack
```

Thousands every second.

SIEM collects everything into one dashboard.

Examples:

Splunk

IBM QRadar

Microsoft Sentinel

Elastic SIEM

---

### DevOps Example

Instead of checking

EC2 logs

Firewall logs

CloudTrail logs

Linux logs

one by one...

SIEM collects everything.

Now the SOC team can investigate attacks easily.
