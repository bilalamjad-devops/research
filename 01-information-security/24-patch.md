Chalein! Is pure question ko 3 chote, aasan hisson mein tod kar samajhte hain:

---

### **1. Patch aur Patch Management Kya Hai?**

* **Patch:** Computer software ka ek **"Update" ya "Repair Kit"** hota hai jo system ki kisi ghalti (bug) ya security ki kamzori ko theek karne ke liye lagaya jata hai.
* **Patch Management:** Pehle se plan karke naye updates ko **dhoondna, test karna, aur sahi systems par install karna** taake computer secure rahe.

---

### **2. Patch Management Ke 4 Main Steps (Exam Order)**

Exam mein in 4 steps ka sequence pucha jata hai:

1. **Step 1: Establish baseline IT assets inventory:** List banao.
Pehle list banao ke tumhari company mein kitne computers, laptops, aur software chal rahe hain.


2. **Step 2: Gather software patch and vulnerability information:** Updates dhoondo.
Microsoft/Google se check karo ke unhon ne kaunse naye security patches release kiye hain.


3. **Step 3: Identify vulnerability relevancy and filter to assign to endpoint:** Relevant patch chunno.
Yeh dekho ke kaunsa patch kis computer ke liye zaroori hai (har patch har machine par nahi lagta).


4. **Step 4: Review, approve and mitigate patch management:** Approve aur Install karo.
Patch ko check/test karo, approve karo, aur machines par install (deploy) kardo.


---

### **3. Patch Na Lagane Ka Nuqsan (Risk)**

* **Malware Attack:** System mein purana bug reh jayega jisse hacker ya virus aram se andar ghus sakta hai.
* **Shorter Timeframe:** Aaj kal patch aane aur hacker ke attack karne ke beech ka time **bohot chota (shorter)** ho gaya hai, isliye jaldi patch lagana zaroori hota hai.

---

> **Exam Key Terms:**
> 1. Patch = Software update / Bug fix.
> 2. Order = **Inventory $\rightarrow$ Gather $\rightarrow$ Filter $\rightarrow$ Approve/Deploy**.
