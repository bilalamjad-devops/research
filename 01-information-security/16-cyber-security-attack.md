In cyber security, **Dictionary Attack**, **DoS Attack**, **Injection Attack**, and **Phishing Attack** are broadly known as:

## 1. **Cyber Security Threats / Cyber Attacks**

These are techniques or malicious methods used by attackers (hackers) to exploit vulnerabilities in computers, networks, or applications to compromise data, gain unauthorized access, or cause damage.

---

## 2. Categorized View (According to Attack Types)

While all of them are **Cyber Attacks**, they fall under different sub-categories based on how they work:

| Attack Name | Category / Type | How It Works / Focus |
| --- | --- | --- |
| **Dictionary Attack** | **Password Cracking / Authentication Attack** | Tries automated lists of common words to guess passwords. |
| **Phishing Attack** | **Social Engineering Attack** | Tricks users (via fake emails/sites) into giving away credentials. |
| **DoS (Denial of Service)** | **Availability / Network Attack** | Overwhelms a server with fake traffic to crash it and block real users. |
| **SQL / Command Injection** | **Application / Software Vulnerability Attack** | Injects malicious code into input fields to manipulate backend databases. |

### Dictionary Attack Kya Hota Hai?

1. **Dictionary Attack** password cracking ka ek tareeqa hai jismein attacker ek automated script/tool chalata hai jismein lakho mashhoor lafz (words), names, aur common passwords ki ek list (dictionary file) hoti hai (jaise `password123`, `admin`, `pakistan`, `dragon`).
2. Tool bari bari in sab words ko try karta hai jab tak sahi password na mil jaye.
3. **Complex Password Ka Fayda:** Agar aapka password complex hoga (jis mein uppercase letters, lowercase letters, numbers, aur special symbols mixed hon), toh wo kisi bhi dictionary wordlist mein nahi hoga. Is tarah system **Dictionary Attack** se safe rehta hai.

---

### Baki Options Kyun Ghalat Hain?

* **B. Injection Attack (e.g., SQLi):** Yeh software code mein validation na hone ki waja se hota hai, iska complex password se koi taalluq nahi.
* **C. DoS Attack (Denial of Service):** Yeh server ko bohot zyada fake traffic bhej kar crash karne ke liye hota hai.
* **D. Phishing Attack:** Yeh fake emails/websites ke zariye user ko bewakoof bana kar info churane ka tareeqa hai. Simple ho ya complex, agar user ne khud hi fake page par password likh diya toh phishing successful ho jayegi.
