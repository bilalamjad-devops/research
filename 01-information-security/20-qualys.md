Q. 43: For creating scanning policies, qualys built in policies library include.

Ans: CIS and DISA policies



**Haan, Qualys aur Nessus bilkul alag-alag tools hain**, alag-alag companies ke banaye hue hain, aur inka kaam karne ka tareeqa bhi thoda mukhtalif hai.

Lekin kyunke dono ka **maqsad ek hi hai** (vulnerabilities dhoondna aur security scan karna), isliye aksar inka naam ek sath liya jata hai.

---

### In dono mein kya farq hai?

| Feature | Qualys | Nessus (Tenable) |
| --- | --- | --- |
| **Company** | Qualys Inc. | Tenable |
| **Architecture** | **Cloud-Based (SaaS):** Iske liye apna server install karne ki zaroorat nahi hoti, sab kuch cloud par web dashboard se manage hota hai. | **On-Premises / Hybrid:** Iska scanner/engine aksar local server par ya user ki machine par install hota hai (Tenable.io cloud version bhi deta hai). |
| **Primary Use** | Enterprise-level continuous monitoring, global asset inventory, compliance, aur cloud security ke liye bohot famous hai. | Duniya ka sab se popular **point-in-time vulnerability scanner** hai, jo quick aur detailed network/system scanning ke liye jana jata hai. |

---

### Dono mein Common Kya Hai?

* Dono ke paas **CIS aur DISA STIG** jaisi built-in security policies hoti hain.
* Dono ka use system ki kamzoriyaan (vulnerabilities) aur misconfigurations pakadne ke liye kiya jata hai.

Jese gaariyan alag alag companies ki hoti hain (Toyota aur Honda), lekin sab ka kaam ek hi hai—safarnama karna. Isi tarah Qualys aur Nessus alag brands hain, par dono **security scanning** ka kaam karte hain.
