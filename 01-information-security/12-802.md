### IEEE 802.1X (Network Access Control - NAC):

**802.1X** ek security standard hai jo **Port-based Network Access Control (PNAC)** provide karta hai.

1. **Kaise Kaam Karta Hai?** Jab bhi koi laptop, phone, ya computer network (Ethernet cable ya Wi-Fi) se connect hone ki koshish karta hai, 802.1X us device ko direct network access nahi deta.
2. **Authentication Required:** Pehle wo device se credentials / certificates maangta hai aur **RADIUS Server** se authenticate karta hai.
3. **Access Control:** Agar device authorized hai, tabhi use network port se connect hone ki ijazat milti hai—warna block kar diya jata hai.

### Baki Options Kyun Ghalat Hain?

* **B. 802.11g:** Yeh Wi-Fi ka purana speed standard hai (up to 54 Mbps).
* **C. 802.11b:** Yeh bhi Wi-Fi ka purana standard hai (up to 11 Mbps).
* **D. 802.11n:** Yeh Wi-Fi 4 standard hai.

> **Key Memory Tip:**
> * **802.11** (a/b/g/n/ac/ax) = **Wi-Fi Standards** (wireless communication speeds).
> * **802.1X** (X at the end) = **Security Access Control** (kaunsa device connect ho sakta hai).
