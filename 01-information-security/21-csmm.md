### **Cyber Security Maturity Model (CSMM) Ke Total 6 Levels:**

CS205 ke curriculum ke mutabiq, **Cyber Security Maturity Model (CSMM)** organization ke security level ko 6 structured stages mein divide karta hai:

| Level / Layer | Name | Description |
| --- | --- | --- |
| **Layer 1** | **Initial / Ad-hoc** | Basic security, koi formal plan ya policies nahi hoti. |
| **Layer 2** | **Repeatable** | Basic procedures set ho jate hain aur follow hotay hain. |
| **Layer 3** | **Defined** | Formal policies aur rules puri organization mein document ho jate hain. |
| **Layer 4** | **Managed** | Security controls ko active tareeqe se manage kiya jata hai. |
| **Layer 5** | **Monitored** | Real-time monitoring, SIEM, SOC, aur continuous threat detection hoti hai. |
| **Layer 6** | **Secured** | Highly mature posture, dynamic risk management, aur ultimate resilience level. |

---

> **Quick Memory Tip:**
> **Level 5:** Monitored (Continuous Monitoring & Detection)
> **Level 6:** Secured (Fully Hardened & Protected)
