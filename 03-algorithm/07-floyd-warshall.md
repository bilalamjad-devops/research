### **Exam Cheat Sheet (Difference clear rakhein):**

| Algorithm | Kya compute karta hai? |
| --- | --- |
| **Dijkstra** | **Single-Source** Shortest Path (Ek starting point se baqi sab tak) |
| **Bellman-Ford** | **Single-Source** Shortest Path (Ek starting point se baqi sab tak) |
| **Floyd-Warshall** | **All-Pairs** Shortest Path (Har point se har doosre point tak) |

> **Ratta Tip:** Exam mein **"All-pairs"** ka word aaye toh foran **Floyd-Warshall** select karein!

---

 Floyd-Warshall = Sab se Slowest Shortest Path Algorithm
