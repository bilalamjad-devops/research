### **Exact Breakdown:**

$$\text{IP Address} = \text{Prefix} + \text{Suffix}$$

* **Prefix = Network Number (Network ID):** Yeh batata hai ke aap kis **network** par hain (jaise ek shehar ka postal code).
* **Suffix = Host Number (Host ID):** Yeh batata hai ke us network ke andar aapka **specific computer/device** kaun sa hai (jaise ghar ka number).

---

### **Quick Example:**

Class C IP Address: `192.168.1.50`

* **Prefix (`192.168.1`):** Network Number (Tamam devices jo is Wi-Fi se connect hongi, unka yeh hissa SAME hoga).
* **Suffix (`.50`):** Host Number (Yeh aapke laptop/mobile ka UNIQUE number hai).
