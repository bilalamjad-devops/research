### **Exact Breakdown:**

$$\text{IP Address} = \text{Prefix} + \text{Suffix}$$

* **Prefix = Network Number (Network ID):** Yeh batata hai ke aap kis **network** par hain (jaise ek shehar ka postal code).
* **Suffix = Host Number (Host ID):** Yeh batata hai ke us network ke andar aapka **specific computer/device** kaun sa hai (jaise ghar ka number).

---

### **Quick Example:**

Class C IP Address: `192.168.1.50`

* **Prefix (`192.168.1`):** Network Number (Tamam devices jo is Wi-Fi se connect hongi, unka yeh hissa SAME hoga).
* **Suffix (`.50`):** Host Number (Yeh aapke laptop/mobile ka UNIQUE number hai).

### **Quick Comparison:**

| Address Type | Formal Name | Size in Bits | Size in Bytes | Example Format |
| --- | --- | --- | --- | --- |
| **IP Address (IPv4)** | Logical Address / Protocol Address | **32 bits** | 4 Bytes | `192.168.1.1` |
| **Ethernet Address** | Physical Address / Hardware Address / MAC Address | **48 bits** | 6 Bytes | `00:1A:2B:3C:4D:5E` |

---

### **Key Concept for CS610 Exam:**

* **IP Address (32-bit):** Network Layer (Layer 3) par use hota hai. Is mein **Prefix** (Network ID) aur **Suffix** (Host ID) hota hai.
* **Ethernet / MAC Address (48-bit):** Data Link Layer (Layer 2) par use hota hai. Yeh network card (NIC) ka permanent hardware address hota hai.

**ARP ka kaam** isi 32-bit IP address ko 48-bit Ethernet (MAC) address mein **Translate** karna hota hai!
