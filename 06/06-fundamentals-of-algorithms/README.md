
Theory of Automata:

**Letter** = Symbol a,b,c etc 

**Alphabet** = Σ (Sigma) = set of symbol e.g., (a,b) 

**String** = sequence of alphabet e.g., Σ(a,b)

**Language** = collection of string 

- fixed numbers of strings = finite
- infinite numbers of strings = infinite 

**Automata?** weather a string is a part of Language or not? 

it is a mathematical model, abstract model, 

Use: does this string {abba} belong to this Language?

Definition:
	
	 A finite non-empty set of symbols (letters), is called an alphabet. It is denoted by Σ ( Greek letter sigma).

Example:
	
	 Σ={a,b}
  
	Σ={0,1} //important as this is the language 		//which the computer understands.
	
	 Σ={i,j,k}

Definition:

	Concatenation of finite symbols from the alphabet is called a string. 

Example:

	If Σ= {a,b} then

		a, abab, aaabb, ababababababababab
