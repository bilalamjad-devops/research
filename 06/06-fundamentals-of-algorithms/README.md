# Alphabet (set of symbols)

<img width="1361" height="1069" alt="image" src="https://github.com/user-attachments/assets/3137ff8b-cde5-4792-b124-895a1ef4b93f" />

Definition:
	
	 A finite non-empty set of symbols (letters), is called an alphabet. It is denoted by Σ ( Greek letter sigma).

Example:
	
	 Σ={a,b}
  
	Σ={0,1} //important as this is the language 		//which the computer understands.
	
	 Σ={i,j,k}

<img width="1383" height="1069" alt="image" src="https://github.com/user-attachments/assets/9326f51e-8221-4175-b214-73077baa91a0" />

Definition:

	Concatenation of finite symbols from the alphabet is called a string. 

Example:

	If Σ= {a,b} then

		a, abab, aaabb, ababababababababab
